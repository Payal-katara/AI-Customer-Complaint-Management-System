AI User Complaint Management System...

What This Project Does?

1. Accepts complaint text from users through a web interface.
2. Supports document-based intake (PDF, DOCX, TXT) and converts content into plain text.
3. Extracts complaint details into structured form fields.
4. Generates a risk score, risk level, and recommended next action.
5. Stores complaint analysis records for review and audit.

Key Features

1. AI User Complaint Management System is a full-stack complaint intake and triage platform that helps teams capture customer complaints.
2. Auto-extract structured fields.
3. Generate a risk assessment for faster follow-up.
